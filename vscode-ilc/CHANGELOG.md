# Change Log

All notable changes to the ILC Syntax Highlighter extension will be documented in this file.

## [0.1.0] - 2026-04-04

### Added
- Initial release with comprehensive syntax highlighting
- Support for all ILC language keywords
- Number literal formats (decimal, hex, binary, octal)
- String literal support (single/double/raw/interpolated)
- Comment support (line and block)
- Language configuration with auto-closing pairs
- Proper bracket matching and indentation rules
